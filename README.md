# WebScrapers

Набор специализированных парсеров для автоматизированного сбора новостных статей с нескольких российских и зарубежных новостных ресурсов: ТАСС, EuroNews, Gazeta.spb.ru и Vtomske.ru. Каждый парсер реализован в виде отдельного класса, инкапсулирующего логику обхода страниц, извлечения ссылок на статьи и парсинга содержимого конкретной новости.

## Описание проекта

Проект представляет собой коллекцию независимых скраперов, каждый из которых нацелен на конкретный новостной сайт. Общая архитектура построена вокруг абстрактного базового класса `BaseScraper`, задающего единый интерфейс для получения списка новостей на странице и парсинга отдельной статьи. Отдельные скраперы (ТАСС, EuroNews) наследуются от этого класса, тогда как скраперы для Gazeta.spb.ru и Vtomske.ru реализованы как самостоятельные классы со схожей, но не унифицированной логикой.

Результатом работы каждого скрапера является набор структурированных данных (список словарей или `pandas.DataFrame`), который сохраняется в формате CSV.

## Поддерживаемые источники

| Источник | Класс | Способ обхода |
| --- | --- | --- |
| ТАСС (tass.ru) | `TassScraper` | Обращение к внутреннему API поиска и контента |
| EuroNews (euronews.com) | `EuroNewsScraper` | Постраничный обход рубрик с обходом защиты через `cloudscraper` |
| Gazeta.spb.ru | `Scrapper` (`GazetaScraper.py`) | Постраничный обход категорий, парсинг HTML |
| Vtomske.ru | `NewsParser` (`VtomskeScraper.py`) | Постраничный обход тематических лент, парсинг HTML |

## Требования

Проект использует Python 3.10+.

Зависимости перечислены в `requirements.txt`:

- `beautifulsoup4==4.15.0` - парсинг HTML-разметки
- `cloudscraper==1.2.71` - обход защиты Cloudflare при обращении к EuroNews
- `pandas==3.0.5` - формирование и сохранение табличных данных
- `PyYAML==6.0.3` - чтение YAML-конфигураций
- `Requests==2.34.2` - выполнение HTTP-запросов
- `tqdm==4.70.1` - отображение прогресса при сборе данных

## Установка

1. Клонировать репозиторий:

```bash
git clone https://github.com/Ilia-Trof88/WebScrapers.git
cd WebScrapers
```

2. Создать и активировать виртуальное окружение (рекомендуется):

```bash
python -m venv venv
source venv/bin/activate  # Linux / macOS
venv\Scripts\activate     # Windows
```

3. Установить зависимости:

```bash
pip install -r requirements.txt
```

4. Создать директорию `data/` и необходимые поддиректории для сохранения результатов (см. раздел "Использование").

## Конфигурация

### ТАСС

Эндпоинты API ТАСС вынесены в файл `config/tass_config.yaml`:

```yaml
tass_endpoints:
  search_url: "https://tass.ru/tbp/api/v1/search"
  content_url: "https://tass.ru/tbp/api/v1/content/"
```

Для корректной работы `TassScraper` дополнительно требуется файл `config/tass_headers.py`, содержащий словарь `tass_headers` с полями `accept`, `user-agent` и `referer`. Данный файл не включен в репозиторий и должен быть создан вручную. Значения заголовков можно получить во вкладке "Сеть" (Network) инструментов разработчика браузера при анализе запросов сайта tass.ru.

## Использование

Каждый источник запускается через соответствующий скрипт из директории `scripts/`. Скрипты являются интерактивными и запрашивают у пользователя необходимые параметры через консоль.

### ТАСС

```bash
python -m scripts.tass_scraping
```

При запуске потребуется указать название рубрики (например, `/moskva`) и количество новостей для сбора. Результат сохраняется в `data/tass_data/<рубрика>.csv`.

### EuroNews

```bash
python -m scripts.euronews_scraping
```

При запуске потребуется указать количество новостей и название выходного файла. Результат сохраняется в `data/euronews_data/<имя_файла>.csv`.

Для работы данного парсера необходимо использовать VPN, если Вы находитесь в России.

### Gazeta.spb.ru

```bash
python -m scripts.gazeta_scraping
```

Скрипт последовательно собирает заданное количество новостей по всем поддерживаемым тематикам. Результат сохраняется в `data/<тематика>.csv`.

### Vtomske.ru

```bash
python -m scripts.vtomske_scraping
```

Скрипт последовательно собирает заданное количество новостей по всем поддерживаемым тематикам. Результат сохраняется в `data/<тематика>.csv`.

Перед запуском скриптов необходимо убедиться в существовании соответствующих поддиректорий внутри `data/`.

## Описание модулей и классов

### scrapers/BaseScraper.py

Абстрактный базовый класс `BaseScraper`, построенный на основе `abc.ABC`. Определяет единый интерфейс для скраперов, использующих постраничный обход.

- `__init__(self, scraper_name: str)` - инициализирует скрапер с указанным названием.
- `_get_page_news()` (абстрактный) - получение всех ссылок на новости с текущей страницы.
- `_parse_single_article()` (абстрактный) - получение информации с одной новостной статьи.

### scrapers/TassScraper.py

Класс `TassScraper(BaseScraper)` реализует сбор новостей с сайта информационного агентства ТАСС через внутреннее API поиска и контента.

- `__init__(self, rubrics: str)` - инициализация с указанием целевой рубрики.
- `_get_page_news(search_api_url, tass_headers, news_limit=30, search_after=None)` - получение списка новостей через API поиска с пагинацией по временной метке (`search_after`), так как сайт использует "бесконечную ленту" без номеров страниц.
- `_parse_single_article(tass_content_url, news_id, rubrics, headers)` - получение полной информации по конкретной новости (заголовок, лид, источник, автор, текст, дата публикации, рубрика, категория).
- `scrape_rubric(search_api_url, tass_headers, tass_content_url, max_retry_attemps=5, search_after=None, max_collected_news=90)` - основной публичный метод, организующий полный цикл сбора новостей по рубрике с обработкой ошибок и ограничением числа попыток.

### scrapers/EuroNewsScraper.py

Класс `EuroNewsScraper(BaseScraper)` реализует сбор новостей с сайта EuroNews. Использует `cloudscraper` для обхода защиты Cloudflare.

- `__init__(self, base_url: str)` - инициализация с указанием базового домена (доступны версии сайта на разных языках).
- `_get_bs_object(target_url)` - вспомогательный метод получения объекта `BeautifulSoup` по URL.
- `_get_page_news(page_url)` - сбор всех ссылок на статьи с текущей страницы рубрики.
- `_parse_headline`, `_parse_lead`, `_parse_date`, `_parse_author`, `_parse_body` - набор приватных методов для извлечения отдельных полей статьи.
- `_parse_single_article(article_url)` - агрегирует результаты приватных методов парсинга в единый словарь; пропускает статьи, содержащие только видео.
- `_get_main_paginator`, `_get_total_num_pages`, `_get_next_page_url`, `_get_current_page_num` - методы навигации по постраничному пагинатору рубрики.
- `parse_rubric(start_url, num_collected_news=100)` - основной публичный метод, организующий полный цикл сбора новостей по рубрике с переходом между страницами.

### scrapers/GazetaScraper.py

Класс `Scrapper` реализует сбор новостей с сайта gazeta.spb.ru. В отличие от ТАСС и EuroNews не наследуется от `BaseScraper`.

- `__init__(self, category: str)` - инициализация с проверкой тематики по списку допустимых значений (Город, Происшествия, Ленобласть, Культура, Спорт, Политика, Наука) и сопоставлением тематики с URL категории.
- `parse_news_article(url)` - сбор данных с одной новостной статьи: заголовок, текст, теги, дата публикации, категория. При ошибке парсинга возвращает словарь-заглушку со значением `Unknown` во всех полях, чтобы не прерывать основной цикл сбора.
- `find_all_urls(url)` - поиск всех ссылок на статьи на странице категории.
- `scrape_news(n_news, save_path)` - основной публичный метод: последовательно обходит страницы категории, собирает заданное количество новостей, исключает записи-заглушки и сохраняет результат в CSV-файл через `pandas.DataFrame`.

### scrapers/VtomskeScraper.py

Класс `NewsParser` реализует сбор новостей с сайта vtomske.ru. Не наследуется от `BaseScraper`.

- `__init__(self, thematic: str)` - инициализация с проверкой тематики по словарю соответствий (Томск, Россия, Мир, Экономика, Политика, Происшествия, Авто, Спорт) и определением URL тематической ленты.
- `parse_single_article(url)` - сбор заголовка и текста статьи путем извлечения тегов `h2`-`h9`, `p` и `ul` с последующей очисткой от HTML-разметки регулярными выражениями.
- `parse_thematic(n_news)` - основной публичный метод: обходит тематическую ленту постранично, собирает заданное количество новостей с индикацией прогресса через `tqdm`.

### src/functions.py

Модуль вспомогательных функций общего назначения.

- `read_yaml_config(config_path: str) -> dict` - безопасное чтение YAML-конфигурации с помощью `yaml.safe_load`.

## Формат собираемых данных

Итоговая структура словаря с данными новости отличается в зависимости от источника:

- ТАСС: `headline`, `lead`, `source`, `author`, `body`, `source_url`, `timestamp`, `tass_rubric`, `category`.
- EuroNews: `headline`, `lead`, `date`, `author`, `article_text`, `source_url`, `root_url`.
- Gazeta.spb.ru: `Headline`, `Body`, `Tags`, `Publishing_Date`, `News_Category`.
- Vtomske.ru: `news_headline`, `news_body`.

Все результаты сохраняются в формате CSV с использованием `pandas.DataFrame.to_csv`.

## Известные ограничения

- Скраперы зависят от текущей HTML-структуры и API целевых сайтов; при изменении разметки или API потребуется соответствующая доработка кода.
- Файл `config/tass_headers.py` не включен в репозиторий по соображениям безопасности и должен быть создан пользователем самостоятельно.
- Структура возвращаемых данных не унифицирована между скраперами, что следует учитывать при последующей обработке собранных датасетов.
- Проект предназначен для образовательных и исследовательских целей.
